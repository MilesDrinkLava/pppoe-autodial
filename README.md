# pppoe-autodial

> Windows 开机自动 PPPoE 拨号 —— 登录即联网，掉线自愈。零常驻、零依赖、纯系统组件。

## 解决什么问题

校园网、宽带拨号（PPPoE）用户每次开机都要手动点一遍"连接"才能上网。
本工具把它变成**登录 Windows 后自动完成**：

- 开机自动拨号，登录后约 5 秒联网
- 可选**掉线自动重连**：断线后 15 秒内自动恢复（默认关闭）
- 双击安装，全程图形向导，不需要管理员权限

## 快速开始

1. 下载本仓库（Code → Download ZIP）并解压到任意用户目录
2. 双击 **`安装.cmd`**
3. 按向导操作：确认拨号连接 → 输入账号 → 输入密码 →（可选）启用掉线重连 → 完成
4. 重启验证：登录后什么都不用做，约 5 秒自动联网

> 被 SmartScreen 提示拦截？点"更多信息 → 仍要运行"（脚本均为纯文本，可自行审阅）。

## 常见问题

**支持校园网 Web 认证（Portal 登录页）吗？**
不。本工具只负责 **PPPoE 拨号层**（宽带连接），与网页认证是两套独立体系，互不影响。

**密码存在哪里？安全吗？**
DPAPI 加密存于 `cred.dat`，只有当前 Windows 账户在本机能解密，文件中不含明文。重装系统/换电脑后需重新输入密码。

**会有后台进程吗？会不会卡顿？**
没有常驻进程。选择"开机拨号"模式时，只有登录瞬间运行约 1 秒；开启掉线守护后每 15 秒运行约 0.6 秒（约 0.2 秒 CPU 时间，八核平均占用约 0.2%），运行完即退出。

**怎么暂停 / 卸载？**
双击 `暂停恢复.cmd` 暂停或恢复；双击 `卸载.cmd` 彻底移除。

**怎么修改掉线检测间隔？**
编辑 `config.ps1` 里的 `$reconnectSeconds`（默认 15 秒，最小 10 秒），再双击 `安装.cmd` 重装一次即可生效。

**为什么任务计划里会出现一个任务？杀毒软件会报警吗？**
拨号由"任务计划 + PowerShell 脚本"驱动（任务名 `AutoDial-<你的连接名>`），所有脚本均为可读纯文本。个别安全软件可能对 VBS 启动器敏感，可自行审阅 `dial-hidden.vbs`（仅 7 行）。

**适用范围？**
任何 Windows 下用"宽带连接(PPPoE)"拨号的场景。部分学校/运营商强制使用专用客户端（如 DrCom 认证工具）的环境不适用。

## 工作原理

```
任务计划（登录触发 + 可选 15 秒错峰触发器）
  └─ dial-hidden.vbs          静默启动器（消除控制台黑框）
       └─ dial.ps1            检测 PPPoE 接口状态
            ├─ 已在线 → 直接退出（幂等，重复触发无害）
            └─ 未在线 → rasdial 拨号，失败自动重试（最多 12 轮）
                          ↓
                     dial.log（运行日志）
```

任务计划服务限制重复间隔不小于 1 分钟，因此 15 秒守护由 4 个错峰触发器实现（各自每 1 分钟、起始错开 15 秒）——纯调度技巧，不引入任何常驻进程。
